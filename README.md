# BlenderPilot Lotus Atlas

Interactive 3D viewer for five modular Blender spaceship components, based on EL4CTEO/blender-skills experiments.

- 8 / 10 / 12 petals (independently baked GLB variants)
- Toggle five component classes
- Orbit / top / side views, autorotate and wireframe
- PNG screenshots
- Three.js r179.1 dependencies included locally in vendor

All geometries were created from the BlenderPilot P2-H asset library, not generated on page load. Technical validation is limited to source Blender QA and sampled collision checks, not engineering certification.

For local use: run Python HTTP server from this folder on port 17872. The hosted site uses only relative paths and requires no API keys.

Research master: https://app.notion.com/p/41b34a28189a81a082bcf59a9b051cc3

## L2 Redesign (2026-11-17)

P2-J rebuilds the geometry with layered curved lotus petals, metallic edge fillets and fiber-optic veins, two lotus-pod command cabins, a fusion torus, six ion thrusters, segmented solar sails, and a scout shuttle. Static 8/10/12 variant GLBs are generated by Blender 5.3. 10-petal source has 430 objects and ~214k export triangles. The L1 baseline is preserved in Git at commit 103d2f9.

Source research: see P2-J in the Notion master page. Artistic mock-up only, not mechanically validated.

### Before/after comparison
The original P2-I minimal L1 model is preserved at /l1/ as a standalone, immutable static site snapshot (Git commit 103d2f9). P2-J L2 uses material-group merged GLBs for lower draw-call counts. Original full-resolution Blender sources and complete unoptimized GLBs remain outside this deployed site, in the personal D: BlenderPilot project.
